# What does my Bambino want?

A quick care guide for the Breville/Sage Bambino and Bambino Plus espresso machines. It tells you what the machine is asking for and walks you through it step by step: cleaning cycle, descaling, and unblocking the steam wand.

**Live site: https://romanshevchuk.github.io/what-my-bambino-wants/**

## Run locally

It's a static site with no build step. Open `index.html` in a browser.

## Structure

- `index.html`: the pages and guide content
- `css/styles.css`: styles
- `js/app.js`: navigation, model switching and step progress
- `img/`: product photos
